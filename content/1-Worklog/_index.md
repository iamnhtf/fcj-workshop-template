### Progress Summary

The internship journey can be divided into four major phases:

1. **Phase 1 (Week 1–3): AWS Foundations & Core Services**
   * Learning Cloud Computing concepts and setting up an AWS account with IAM.
   * Building networking foundations with Amazon VPC, Subnets, Security Groups, EC2, NAT Gateway, and Site-to-Site VPN.
   * Exploring advanced EC2 deployment, Amazon RDS, and database backup/restore operations.

2. **Phase 2 (Week 4–6): Scalability, Networking & Project Kickoff**
   * Learning AWS scalability services including ELB, Auto Scaling, CloudWatch, and AWS Budget.
   * Understanding DNS with Amazon Route 53 and managing resources with AWS CLI.
   * Exploring advanced networking with VPC Peering and AWS Transit Gateway.
   * Beginning Snaptics backend development with transaction processing and item inventory features.

3. **Phase 3 (Week 7–10): Storage, Security & Project Development**
   * Learning Amazon S3, AWS Backup, Storage Gateway, Amazon SNS, Amazon FSx, AWS Security Hub, and AWS Lambda.
   * Understanding AWS Resource Tags, Resource Groups, IAM, AWS KMS, CloudTrail, and IAM Role security.
   * Developing Snaptics features including AI Assistant, S3 integration, and Income Source.

4. **Phase 4 (Week 11–12): Security Review, Project Completion & Documentation**
   * Researching AWS security best practices and learning IAM Roles for EC2 applications.
   * Implementing Hangfire job scheduling, Budget Income Source, and Support Ticket modules for Snaptics.
   * Completing backend testing, project documentation, and preparing the final presentation.
