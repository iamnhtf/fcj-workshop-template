### Progress Summary

The internship journey can be divided into four major phases:

1. **Phase 1 (Week 1–3): AWS Foundations & Core Services**
   * Learning Cloud Computing concepts and setting up an AWS account with IAM.
   * Building networking foundations with Amazon VPC, Subnets, Security Groups, EC2, NAT Gateway, and Site-to-Site VPN.
   * Exploring advanced EC2 deployment, Amazon RDS, and database backup and restore operations.

2. **Phase 2 (Week 4–6): Scalability, Networking & Project Kickoff**
   * Learning AWS scalability services including Elastic Load Balancing (ELB), Auto Scaling, CloudWatch, and AWS Budgets.
   * Understanding Amazon Route 53, AWS CLI, VPC Peering, and AWS Transit Gateway.
   * Beginning the development of the Snaptics backend with core transaction management features.

3. **Phase 3 (Week 7–10): Storage, Security & Feature Development**
   * Learning Amazon S3, AWS Backup, Storage Gateway, Amazon SNS, Amazon FSx, AWS Security Hub, and AWS Lambda.
   * Exploring AWS Resource Tags, Resource Groups, IAM, AWS KMS, CloudTrail, and IAM security best practices.
   * Developing major Snaptics features including AI Assistant, Amazon S3 integration, OCR processing, and Income Source management.

4. **Phase 4 (Week 11–13): Deployment, Documentation & Project Completion**
   * Implementing Amazon SQS, Hangfire background jobs, Budget Income Source, and Support Ticket modules.
   * Deploying the system on AWS, testing the complete workflow, resolving integration issues, and preparing the final project demonstration.
   * Completing the Proposal, Workshop, internship documentation, and final project submission.
