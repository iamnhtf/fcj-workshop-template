### Week 9 Objectives

* Understand AWS resource tagging concepts and best practices for organizing cloud resources.
* Learn to manage resource tags using the AWS Management Console and AWS CLI.
* Explore AWS Resource Groups for organizing and managing AWS resources.
* Build a foundational understanding of IAM users, policies, and roles for secure access control.
